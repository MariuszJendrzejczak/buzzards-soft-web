# Harvest log

Verdicts on lessons swept from consuming projects. Append-only; written when a lesson is
decided, read by `/canon-harvest` so the same entry is never re-litigated on the next sweep.

A verdict here is a decision about **where a rule lives**, and "not canon" is a common and
legitimate one: `docs/canon/**` governs code in consuming projects, while a rule about how the
framework's own skills write their artifacts belongs in `shared/**` and travels as toolchain.

## Lessons the canon now holds

One row per lesson whose rule a `Promote` verdict above moved, whole, into `docs/canon/**` or the
toolchain — the exact heading it has in its project's `context/foundation/lessons.md`. A lesson
promoted only in part is not listed: the rest of it is still undecided and stays in the project.

`/canon-update` reads this table in each consuming project, removes from that project's
`lessons.md` every entry whose heading is listed, and records the removal in the project's
`docs/canon/.framework` (`lessons_removed`). Nothing writes into a project's `lessons.md` from
here. This repository runs no `/canon-update`; its own rows were removed in the change that
added them.
